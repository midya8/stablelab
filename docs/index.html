For candidate M, remove each rule with not a where a is in M. Remove default-negated literals from every surviving rule. The remaining positive rules are its Gelfond-Lifschitz reduct.

A stable model equals the reduct's least definite closure and satisfies every constraint. Circular justification alone is not enough. These are established finite semantics, not a new solving algorithm.

Two reconstructions. Different work.

The generator builds each reduct and grows its least closure in synchronous rounds. The separate Python checker enumerates every reduct model and every proper candidate subset; it uses model intersections and bounded proof heights to check closure and rounds. It also checks every unfounded-subset obligation. Strict input validation is shared. Browser JSON is independently checked only after stablelab verify evidence.json accepts it.
