EXACT SCOPE / FINITE FACT INPUTS

Two views of one guarantee.

For each Y, keep the diagonal SE pair and the proper SE pairs whose X cannot be extended to another proper SE pair below Y. These are UE pairs. For finite programs, equal UE sets characterize uniform equivalence. The page also enumerates all 2ⁿ fact sets and computes both stable families directly. It reports the two checks separately and requires their verdicts to agree.

The Python verifier reconstructs SE evidence through the existing independent three-valued checker, then reconstructs all fact-context candidates through definite-model intersections and proper-subset reduct models, without calling either generator. Shared parsers and the base evidence checker are disclosed. The JavaScript view is a portable generator, not another independent solver.

At most five declared atoms and 24 normal rules per side, constraints included. Added contexts contain only positive facts from that same vocabulary. No disjunction, variables, aggregates, classical negation, update-semantics or fresh-atom context claim. The broader syntax of cited papers is not implemented.
