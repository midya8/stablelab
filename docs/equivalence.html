Each pair X ⊆ Y asks two questions: does Y satisfy the original program, and does X satisfy its reduct at Y? Identical SE sets mean safe replacement under every finite normal-rule context over this declared vocabulary.

Classical agreement and today's stable-model agreement are weaker tests. The atlas checks all 3ⁿ pairs, not a sample of possible contexts.

WHAT THIS PROVES

Finite evidence, exact scope.

The comparison accepts at most five sorted unique atoms and 24 normal rules per side, including constraints. All atoms must be declared. It does not accept disjunction, choice rules, aggregates, variables, classical negation, or nested default negation. The UI's strong-equivalence claim is restricted to normal contexts over that same vocabulary, not arbitrary syntax or update semantics.

For a differing pair, the context contains facts from Y if the outside program rejects Y. Otherwise it contains facts from X and a directed positive cycle over Y \ X. Below Y, that cycle forces the remaining atoms all together or none. When there is just one remaining atom no cycle rule is needed. The exported report checks the context's subset models and both augmented stable families.

The generator uses direct reduct satisfaction. The Python comparison verifier reconstructs every pair through independent three-valued implication, and recomputes context families by exhaustive proper-subset model tests, without importing either generator. Shared strict parsers and the base evidence verifier are disclosed, not independent layers. The cycle gadget is an implementation specialization of the published complete-edge construction, with the same two-submodel property checked explicitly.
